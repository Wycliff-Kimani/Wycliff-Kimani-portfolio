# Wycliff Kimani — Personal Portfolio

**Live URL:** [https://wycliffkimanik.netlify.app](https://wycliffkimanik.netlify.app)

A professional, modern, and fully responsive personal portfolio website showcasing the skills, projects, and services of Wycliff Kimani, Senior Software Engineer and CEO of DevCraft Technologies.

## 🛠 Tech Stack
* **HTML5** & **CSS3**
* **Bootstrap 5** (UI Framework)
* **JavaScript** (Vanilla JS)
* **AOS** (Animate On Scroll)
* **Typed.js** (Hero typing animation)
* **Swiper** (Carousels/Sliders)
* **Isotope** (Portfolio sorting & filtering)
* **GLightbox** (Image/video lightboxes)
* **Formspree** (Serverless contact form)

## 📂 Pages
* **Home:** Engaging hero section with Typed.js animation.
* **About:** Professional summary, coding stats, and skills overview.
* **Resume:** Educational background and professional experience timeline.
* **Services:** Detailed offerings including Web/Mobile Development, AI/ML Solutions, and Cybersecurity.
* **Portfolio:** A filterable gallery of 36+ completed projects.
* **Contact:** Working contact form linked directly to email.

## ✨ Key Features
* **Typed.js Hero Animation:** Dynamic, cycling titles in the hero section displaying core competencies.
* **Scroll Animations:** Smooth reveal animations as the user scrolls down, powered by AOS.
* **Portfolio Filtering:** Easily sort projects by categories (e.g., Web Development, AI, E-commerce, Mobile) using Isotope.
* **Working Contact Form:** Powered by Formspree—requires no backend or PHP server, fully functional on static hosting platforms like Netlify.
* **Responsive Design:** Mobile-first layout that looks perfect on all device sizes.
* **SEO Optimized:** Comprehensive meta tags and descriptors configured for strong search engine visibility.

## 🚀 How to Run Locally
No complex installation or build step is required!
1. Clone or download this repository.
2. Navigate to the project directory.
3. Open index.html (or FolioOne/index.html) directly in your web browser, or use a tool like VS Code Live Server.

## ✉️ Contact Form Configuration
The contact form relies entirely on [Formspree](https://formspree.io). It does not require a backend server. 
To use your own Formspree endpoint:
1. Register at Formspree and create a new project.
2. Replace the ction URL in the <form> configuration inside contact.html and service-details.html with your custom endpoint.
